## About

Explore key design patterns with a focus on the Singleton pattern. Gain insights into its classification, benefits, limitations, and practical applications, including creating a robust database connection manager.

## Prerequisites

- tktk
- tktk
- tktk

## Content

| Lesson | Time | Learning Objectives |
| ------ |:----------:|:------ |
| [What is a Design Pattern?](./what-is-a-design-pattern/README.md) | 15 min | Recognize design patterns and their classification into creational, structural, andn behavioral catagories.  |
| [Singleton Design Patterns](./singleton-design-patterns/README.md) | 30 min | Examine the advantages and limitations of Singleton design patterns.  |
| [Signleton Design Code-Along](./singleton-design-pattern-code-along/README.md) | 20 min | Practice applying the Singleton design pattern to create a robust database connection manager, ensuring a single instance manages a database connection.  |
| **Total content**  | 65 min |  |
