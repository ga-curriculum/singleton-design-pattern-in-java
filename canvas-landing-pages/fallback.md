## About

Often in programming we often encounter *solved* problems. This means that someone has already faced the design problem we're facing and has solved it in an optimal way. This is also true for application architecture and design. There are many common problems that we face when designing applications, and there are many common solutions to these problems. These solutions are called *design patterns*.

Design patterns are general reusable solutions to common problems in software design. As Java developers, we need to be aware of some of the most widely used patterns so that we don't reinvent the wheel. Singleton is one of those patterns, and is one of the most commonly used design patterns in Java.
