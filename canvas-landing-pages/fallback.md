## About

An application log is a record of all significant events happening during an application's runtime. But, how can we ensure that all the java developers, working from different geographies and developing various application components, dont create their own individual log functions. This is a typical design problem. 

A design problem is an obstacle or challenge that arises during the coding of a program which needs the developer to make decisions on structure or algorithm. From applications that we've use, we've witnessed that there's only only one log file and there is a standardized patter of the log messages. 

This means that someone has already faced the design problem we’re facing and solved it. The best design for our problem already exists. As java developers, we need to be aware of those designs so that we don't reinvent the wheel. This is where design patterns help us.
