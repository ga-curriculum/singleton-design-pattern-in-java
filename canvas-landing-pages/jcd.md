## About

Explore key design patterns with a focus on the Singleton pattern. Gain insights into its classification, benefits, limitations, and practical applications, including creating a robust database connection manager.

## Content

| Lesson | Time | Learning Objectives |
| ------ |:----------:|:------ |
| [What is a Design Pattern?](../what-is-a-design-pattern/README.md) | 10 min | Recognize design patterns and their classification into creational, structural, and behavioral catagories.  |
| [Singleton Design Patterns](../singleton-design-patterns/README.md) | 25 min | Examine the advantages and limitations of Singleton design patterns.  |
| [Singleton Design Code-Along](../singleton-design-pattern-code-along/README.md) | 25 min | Practice applying the Singleton design pattern to create a robust database connection manager, ensuring a single instance manages a database connection.  |
| **Total content**  | 60 min |  |
